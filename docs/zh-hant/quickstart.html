快速開始：給 Claude Code、Codex、agy 的共享記憶

你需要一個 GitHub 帳號和大約十分鐘。一條命令建立一個屬於你的私人記憶倉庫；再一條命令接上你用的每個代理。之後每個工作階段一開始就拿到和任務相符的記憶；有提交工作的工作階段，結束前會停一次，問你哪些值得留下。

BEFORE YOU START

事前準備

工具檢查說明
Git 2.xgit --version
Node.js 22node --versionnpm 隨附
GitHub CLI 2.xgh auth statusbrew install gh，再執行 gh auth login
GitHub 帳號你的記憶會存在它底下的私人倉庫

設定精靈支援 macOS 與 Linux。Windows 請照 README 的逐步安裝指南操作。

STEP 1

建立你的記憶倉庫

git clone https://github.com/RxAi-Aus/amp.git my-agent-memory
cd my-agent-memory
npm install
npm run setup -- --dry-run   # 先看每個步驟；不會改任何東西
npm run setup

精靈會替你的記憶建立一個私人倉庫（絕不推送到範本）、讓 GitHub Actions 能寫入索引、加上協定使用的 Issue 標籤、帶你建立細粒度存取權杖並妥善保存、註冊 GitHub MCP 伺服器，最後編譯索引並發一則真正的測試 Issue。某一步失敗時，它會印出該步的手動命令；再跑一次精靈就從中斷處繼續，而且絕不重置已經上線的倉庫。

STEP 2

接上你的代理

Hook 決定記憶何時流動；內附的 rxai-amp skill 告訴代理怎麼讀寫。你用哪個代理，就跑哪一行。L2 代表由 hook 遞送記憶；L1 代表代理知道協定、自己讀取記憶。各級差別見總覽。

代理命令你會得到
Claude Codenpm run hooks:install:claudeL2：開始時注入指標、依每個提示展開相符的摘要、有提交時停一次檢查點，並附 /amp 命令
Codexnpm run hooks:install:codexL2：開始時注入記憶與檢查點。之後在 Codex 開一次 /hooks，信任新的 hook
agynpm run hooks:install:agyL2：第一次回覆前注入記憶，加上檢查點
OpenClawnpm run hooks:install:openclawL1：把協定摘要寫進它的工作區 AGENTS.md
Hermesnpm run hooks:install:hermesL1：把協定摘要寫進 ~/.hermes/SOUL.md，不在專案資料夾裡也會載入
任何你會提交的倉庫npm run hooks:install:capture -- /path/to/repo每次 git commit 後提醒記錄，給沒有 hook 的代理

任何安裝程式加上 -- --dry-run，就能在真的修改之前先看它要改什麼。

STEP 3

確認它能運作

  1. 在任何倉庫開一個新的 Claude Code 工作階段。它的上下文開頭會有一段以 === RxAi AMP shared memory — RECALL 開始的區塊。如果沒有這段，代表 hook 沒裝好或還沒被信任；代理會直接告訴你，而不是自己手動翻索引。
  2. npm run setup:verify 隨時可以重跑整份檢查清單。
  3. 在 Claude Code 裡，/amp status 會顯示它找到的記憶倉庫與代理名稱。
DAILY USE

第一條記憶與日常循環

/amp update
在 Claude Code 輸入 /amp update <要記住的事>，會依協定的標題格式發一則記憶 Issue，或在它所屬的討論串留一則 Outcome: 留言。只打 /amp update 則會存下這個工作階段的摘要。
RECALL
Hook 在工作階段開始時交給代理指標，並依每個提示展開相符紀錄的摘要。完整記憶只要一個 gh issue view。
CAPTURE
工作階段有提交工作卻沒寫記憶時，檢查點會停一次，請代理寫一條記憶，或用一行說明為何略過。
OUTCOME
在用過的記憶上標 Outcome: success 或 Outcome: failure。下次編譯索引時權重跟著升降，有用的記憶會浮上來。
AMP_DISABLE=1
讓單一工作階段關閉所有 hook。
