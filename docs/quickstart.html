Quickstart: shared memory for Claude Code, Codex and agy

You need a GitHub account and about ten minutes. One command creates a private memory repository that you own; one more connects each agent you use. From then on every session starts with the memories that match its task, and a session that committed work ends with one checkpoint asking what is worth keeping.

BEFORE YOU START

What you need

ToolCheckNotes

The setup wizard runs on macOS and Linux. On Windows, follow the step-by-step guide in the README.

STEP 1

Create your memory repository

git clone https://github.com/RxAi-Aus/amp.git my-agent-memory
cd my-agent-memory
npm install
npm run setup -- --dry-run   # see every step first; changes nothing
npm run setup

The wizard creates a private repository for your memories (it never pushes to the template), lets GitHub Actions write the index, adds the issue labels the protocol uses, walks you through a fine-grained access token and where to keep it, registers the GitHub MCP server, and finishes by compiling the index and posting a real test issue. If a step fails it prints the manual command for it; running the wizard again resumes, and it never resets a repository that is already live.

STEP 2

Connect your agents

Hooks decide when memory moves; the bundled rxai-amp skill tells the agent how to read and write it. Run the line for each agent you use. L2 means the hooks deliver memory; L1 means the agent is told the protocol and reads memory itself. The overview explains the levels.

AgentCommandWhat you get
Claude Codenpm run hooks:install:claudeL2: pointers at session start, summaries matched to each prompt, a checkpoint when work was committed, and the /amp command
Codexnpm run hooks:install:codexL2: memories at session start and the checkpoint. Open /hooks in Codex once and trust the new hooks
agynpm run hooks:install:agyL2: memories before the first reply and the checkpoint
OpenClawnpm run hooks:install:openclawL1: the protocol digest in its workspace AGENTS.md
Hermesnpm run hooks:install:hermesL1: the protocol digest in ~/.hermes/SOUL.md, loaded even outside a project folder
Any repository you commit fromnpm run hooks:install:capture -- /path/to/repoA capture reminder after each git commit, for agents without hooks

Add -- --dry-run to any installer to see what it will change before it changes anything.

STEP 3

Check that it works

  1. Start a new Claude Code session in any repository. Its context now opens with a block that starts === RxAi AMP shared memory — RECALL. If the block is missing, the hooks are not installed or not trusted, and the agent says so instead of searching the index by hand.
  2. npm run setup:verify re-runs the whole checklist whenever you like.
  3. In Claude Code, /amp status shows which memory repository and agent name it resolved.
DAILY USE

Your first memory, and the daily loop

/amp update
In Claude Code, /amp update <what to remember> posts a memory issue in the protocol’s title format, or an Outcome: comment on the thread it belongs to. On its own, /amp update stores a summary of the session.
RECALL
Hooks hand the agent pointers at session start and the summaries of records that match each prompt. A full memory is one gh issue view away.
CAPTURE
When a session committed work and wrote no memory, the checkpoint stops it once and asks for a memory or a one-line reason to skip.
OUTCOME
Mark Outcome: success or Outcome: failure on the memories you used. The next index compile raises or lowers their weight, so what worked rises.
AMP_DISABLE=1
Turns every hook off for one session.
